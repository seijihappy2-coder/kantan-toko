# かんたん投稿

農家の方がスマホから「写真 → ひとこと → 送信」の3ステップで、WordPressのブログを更新できるようにするプラグインです。
秀明自然農法の農場で実際に使うために作りました。同じように困っている農場・団体でお使いいただけます。

LINE公式アカウントからの投稿にも対応しています（任意）。

- 送られた記事は**そのまま公開**か**下書きで保存**かを選べます（管理画面で切り替え）
- 管理者は**同じページの「確認・公開」画面**から、スマホだけで公開・非公開の切り替えと文章の手直しができます（WordPressの管理画面を開く必要はありません）
- 写真は**スマホのブラウザの中で長辺1600pxのJPEGに縮小**してから送るため、電波が弱くても送信できます
- ログインは**合言葉ひとつ**（生産者全員で共有）。WordPressのアカウントは配りません
- 定型文は共通の雛形を用意しつつ、各自が「自分の定型文にする」で自分の形に差し替えられます（その端末だけに保存）
- 名前は生産者が自分で入力して登録。カテゴリも投稿画面から新規作成できます（「マルシェ活動」は最初から入っています）

---

## 更新について

このプラグインは**GitHubの新しい版を自分で見つけます**。新しい版が出ると、WordPressの
「プラグイン」画面に「更新があります」と出るので、クリックすれば更新されます。

**プラグイン一覧で「自動更新を有効化」を1回押しておけば、以降は何もしなくても更新されます。**

※ この仕組みが入っているのは v1.10.0 以降です。それより古い版からは、1回だけzipで入れ替えてください。

## 1. 入れる（5分）

1. `kantan-toko.zip` を用意する（[最新版](https://github.com/seijihappy2-coder/kantan-toko/releases/latest)）
2. WordPress管理画面 → **プラグイン** → **新規プラグインを追加** → **プラグインのアップロード**
3. zipを選んで **今すぐインストール** → **プラグインを有効化**

## 2. 設定する（5分）

管理画面の左メニューに **かんたん投稿** が増えます。開いて次を設定してください。

| 項目 | 設定の目安 |
| --- | --- |
| 合言葉 | 生産者全員に伝える言葉。例：`ibaraki-hatake` |
| 管理者用の合言葉 | 確認・公開をする人だけが使う言葉。例：`kanri-2026`。**生産者には伝えない** |
| 生産者の名前 | 1行に1人ずつ。空でもOK（生産者が投稿時に入力した名前が自動で足されます） |
| 送られた記事の扱い | 運用に合わせて選ぶ（そのまま公開／下書きで確認後に公開） |
| 既定のカテゴリ | 「畑の様子」など、いちばん使うもの |
| 守るカテゴリ | 触らせたくないカテゴリ（農法の説明記事など）。初期値はなし |
| お知らせメール | 新しい記事が届いたときの通知先 |
| 記事の作成者 | **専用アカウントを作って指定**（下記） |
| 写真の枚数 | 既定は8枚 |
| 困ったときの連絡先 | 投稿ページの「困ったときは」に出ます。空なら出ません |
| 定型文 | 全員共通の雛形。`{日付}` が今日の日付に変わります。空にするとボタンが出ません |
| 投稿ページのURL | 既定は `kantan-toko` |

### 記事の作成者について

個人のアカウントではなく、**このツール専用のアカウント**を作って指定してください。

1. WordPress → ユーザー → 新規追加
2. ユーザー名は人名でないもの（例：`farm-post`。あとから変更できません）、
   表示名は「農場だより」など、権限は**寄稿者**、パスワードは自動生成のまま（誰もログインしません）
3. 「かんたん投稿」の**記事の作成者**でそのアカウントを選ぶ

個人名義にしないことで、担当が替わってもアカウントを消せますし、著者アーカイブ（`/author/ユーザー名/`）に
個人名が出ません。万一そのアカウントが乗っ取られても寄稿者権限なら被害が小さく済みます。

寄稿者は通常は記事を公開できませんが、このツールはWordPressに直接書き込むため、
**寄稿者名義でもそのまま公開されます**。

**保存する** を押すと、画面の上に生産者へ伝えるURLが出ます。

> URLを変えた直後にページが表示されないときは、**設定 → パーマリンク** を一度開いて保存してください。

## 3. 生産者に伝える

伝えるのは次の2つだけです。

- 投稿ページのURL（例：`https://example.com/kantan-toko/`）
- 合言葉

投稿ページの一番下に「困ったときは」が畳んで入っているので、その場で読めます。
あわせて同梱の `使い方-生産者向け.md` を印刷して渡せます。
スマホでURLを開き、ブラウザの共有ボタンから **ホーム画面に追加** しておくと、アプリのように1タップで開けます。

## 生産者が自分の記事の状態を見る

投稿フォームの下の **自分の投稿** を開くと、入力した名前で送った記事が新しい順に10件、
**公開中／下書き** の表示つきで並びます。「見る」でそのページを開けます。
操作（公開・非公開の切り替えや削除）はできません。管理者だけの操作です。

## 4. スマホで確認して公開する（管理モード）

新しい投稿が届くとお知らせメールが来ます。メールのリンクから投稿ページを開き、
**管理者用の合言葉**で入ると、画面の上に「投稿する／確認・公開」の切り替えが出ます。

「確認・公開」を開くと、新しい順に30件が並びます。各記事でできること：

| ボタン | 内容 |
| --- | --- |
| 公開する | ブログに載せます |
| 非公開にする | ブログから下げて下書きに戻します（いつでも公開し直せます） |
| 見る | 公開中の記事はそのページ、下書きはプレビューを開きます |
| 直す | タイトルと文章を書き直します（**このツールから送られた記事のみ**） |
| カテゴリを整理する | 一覧の上。カテゴリの追加・名前変更・削除ができます |
| ゴミ箱 | ゴミ箱へ移します。元に戻すのはWordPressの管理画面からになります |

- カテゴリを削除すると、その記事はWordPressの既定カテゴリへ移ります（記事は消えません）
- 写真は1枚目がアイキャッチ画像になります
- 写真の追加・削除・差し替えはこの画面ではできません。写真を変えたいときは、生産者にもう一度送ってもらうか、WordPressの管理画面で編集してください
- パソコンの管理画面でも従来どおり編集できます。投稿一覧には **生産者** 欄が出て、誰が送ったか・LINE経由かが分かります

## 写真ギャラリー

投稿された写真を自動で並べるギャラリーを作れます。写真を選んで並べる作業は要りません。

### 置き方（1回だけ）

1. WordPressで「写真ギャラリー」のページをElementorで編集
2. **ショートコード**ウィジェットを置き、次を入力して保存
   ```
   [kantan_gallery]
   ```

以上です。**公開中の記事で使われている写真**（アイキャッチ画像と、記事に入れた写真）が新しい順に並びます。
プラグインを入れる前に書いた記事の写真も対象です。ページのデザイン用に置いた画像は記事に紐づかないため入りません。

- 写真はすべて正方形に切り抜いて並ぶので、縦・横が混ざっても整って見えます
- 押すと大きく表示され、左右で送れます。下に記事へのリンクが出ます
- 下の方の写真は画面に入るまで読み込まないので、枚数が増えても重くなりません
- 枚数や列を変えるとき: `[kantan_gallery limit="100" columns="3"]`（既定は200枚・4列。画面が狭いときは自動で3列・2列になります）
- **カテゴリで絞るとき**: `[kantan_gallery category="マルシェ活動"]`
  マルシェのページにはマルシェの写真だけ、というように常設の一覧が作れます

### 載せたくない写真を外す

投稿ページの「確認・公開」→ **ギャラリーの写真** を開き、写真を押すと出す／隠すが切り替わります。薄く表示されているものが隠れている写真です。記事からは消えません。

記事を下書きに戻すと、その記事の写真はギャラリーからも消えます。

## LINEから投稿する（任意）

使う場合のみ設定してください。**生産者がLINEに写真を送り、続けて文章を送ると記事（下書き）になります。**

### 準備

1. [LINE Developers](https://developers.line.biz/) でプロバイダーを作り、**Messaging API** のチャネルを作成
2. チャネル基本設定の **チャネルシークレット** を控える
3. Messaging API設定で **チャネルアクセストークン（長期）** を発行して控える
4. 同じ画面の **応答メッセージ** をオフ、**Webhook** をオンにする
5. **Webhook URL** に次を登録する
   ```
   https://example.com/wp-json/kantan-toko/v1/line
   ```
   （管理画面「かんたん投稿」にも同じURLが表示されます）
6. WordPressの「かんたん投稿」画面で **LINE連携を使う** にチェックし、シークレットとトークンを貼り付けて保存

### 投稿できる人を限る

空のままだと、**友だち登録した人は誰でも投稿できます**。限定する場合は「投稿できる人」に

```
Uxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx,ハウス担当
Uyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyy,田んぼ担当
```

のように書きます。ユーザーIDは、その人が一度メッセージを送ったあと、
WordPress側のメール通知や投稿の「生産者」欄に出る表示名をもとに確認するか、
LINE Official Account Manager から確認してください。

### 生産者の操作

1. 写真を送る → 「写真を受け取りました（1枚）」と返事が来る
2. 続けて文章を送る → 「下書きとして保存しました」と返事が来て、記事になる
3. 写真を送り直したいときは **取消** と送る

写真だけ送って1時間ほったらかすと、その写真は記事に使われなくなります（メディアライブラリには残ります）。

## 仕組みと注意点

- **守るカテゴリ**に指定したカテゴリは、投稿ページの選択肢に出ず、名前変更も削除もできません。
  その記事も「確認・公開」「自分の投稿」に出ず、公開・非公開の切り替えも削除もできません。
  農法の説明記事など、生産者の日常投稿と混ぜたくないカテゴリに使ってください
- **固定ページにはいっさいさわりません**。トップページや農法の説明ページなどサイトの骨組みは、
  ツールの一覧に出ず、公開・非公開の切り替えも削除もできません（ブログ記事だけが対象）
- 記事の削除は**ゴミ箱まで**で、完全には消しません。戻すときはWordPressの管理画面から
- 投稿ページは `noindex` を付けているため、検索には出ません。ただし**URLと合言葉を知っている人は誰でも投稿できます**。外部に漏れたら合言葉を変えてください
- 管理者用の合言葉を知っている人は、公開・非公開の切り替えと、届いた記事の文章を読むことができます。生産者には渡さないでください
- 管理者用の合言葉を設定しなければ、管理モードそのものが使えません（設定画面から削除もできます）
- どちらの合言葉もハッシュ化して保存され、平文では残りません。スマホ側には合言葉が保存されます（次回から入力不要）
- 同じ回線からの送信は1時間に40回、合言葉の確認は20回、管理操作は200回までに制限しています
- HEICなど一部の形式は、ブラウザ内でJPEGに変換してから送ります。変換できなかった場合は元のファイルを送るため、WordPressが受け付けない形式だとエラーになります
- プラグインを削除しても、投稿された記事と写真は残ります

## 毎回の記事に同じ案内を入れる

管理画面の **記事の下に入れる動画** にURLを入れると、すべての記事の本文の下に自動で表示されます。
紹介動画のように毎回載せたいものに使ってください。

記事そのものには書き込まないので、**URLを変えれば過去の記事もまとめて変わります**。空にすれば全部から消えます。

## 記事を整然と保つ

1つの記事に何日分もの出来事を書き足していくと、だんだん読みにくくなります。性質で分けてください。

| 内容 | 置き場所 |
| --- | --- |
| 変わらないもの（活動の趣旨、出店者の紹介、申込先） | 固定ページか常設の記事に1枚 |
| 入れ替わるもの（次回の開催日、募集中の講座） | その固定ページの上の方。書き換える |
| 増えていくもの（その日の様子、収穫の記録） | かんたん投稿で**1日1記事**。カテゴリを付ける |
| 毎回載せたい動画 | 上記の「記事の下に入れる動画」 |

増えていく記録を1日1記事にしておくと、カテゴリの一覧がそのまま活動の記録になり、
`[kantan_gallery category="カテゴリ名"]` で写真の一覧も作れます。

## 安全のために

このツールの鍵は**合言葉だけ**です。次を守れば実害はまず出ません。

- 合言葉は**8文字以上**（短いと保存できません）。推測されにくい語を2つつなげる形が楽で強い。例：`hatake-asaichi-26`
- **管理者用の合言葉は生産者に渡さない**
- 人が入れ替わったら合言葉を変える。年1回でも変える
- 合言葉の入力が1時間に10回以上失敗すると、お知らせメールが届きます。心当たりがなければ変更してください

合言葉が漏れた場合にできるのは、投稿と（管理者用なら）公開・非公開の切り替え、ゴミ箱への移動までです。
**固定ページの編集、WordPressの設定変更、ユーザーの追加、プラグインの操作はできません。**

同じ回線からの送信は1時間に40回、合言葉の確認は20回、管理操作は200回までに制限しています。
写真は1枚12MBまで・1回8枚までです。

## 動作環境

- WordPress 6.0 以上 / PHP 7.4 以上
- iOS Safari、Android Chrome の最近のバージョン

## ファイル構成

```
kantan-toko/
├── kantan-toko.php               プラグイン本体
├── includes/
│   ├── class-skt-settings.php    設定の読み書き
│   ├── class-skt-media.php       写真の取り込み
│   ├── class-skt-post-creator.php 記事づくり（フォーム・LINE共通）
│   ├── class-skt-rest.php        投稿を受け取る窓口
│   ├── class-skt-frontend.php    投稿ページの表示
│   ├── class-skt-gallery.php     写真ギャラリー
│   ├── class-skt-line.php        LINE連携
│   └── class-skt-admin.php       管理画面
└── assets/
    ├── app.css                   投稿ページの見た目
    └── app.js                    写真の縮小と送信
```
